# ✍️ AIライティングツール（Streamlit + Gemini 版）

自分のPCで動かす、個人用のAIライティングツールです。データベースやログインはありません。
メール返信・要約・校正・言い換え・翻訳・文章作成・タイトル案の7種類を使えます。

## はじめかた（初回だけ）

1. Gemini の API キーを取得する（https://aistudio.google.com/apikey）
2. このフォルダの `.env.example` をコピーして名前を `.env` に変える
3. `.env` を開き、`GEMINI_API_KEY=` の後ろを自分のキーに書き換えて保存

## 起動

`start.bat` をダブルクリックすると、ブラウザで http://localhost:8501 が開きます。
初回は必要なものを自動でインストールするため、数分かかることがあります。
終了するときは、黒い画面を閉じます。

## カスタマイズ

- **画面の選択肢やAIへの指示を変えたい** → `tools.py`
- **モデルを変えたい** → `.env` の `GEMINI_MODEL`

## メモ

- 自分のPC（127.0.0.1）からしかアクセスできない設定です。
- 利用料金や無料枠、レート制限は Google のアカウント設定と料金プランに従います。
